A one-page newspaper that sums up the world's news on **Tuesday 24 November 2026**: Poland on alert as a Russian drone crosses its border, the search after the Indonesia factory blaze, COP31 climate talks collapsing and ending without a deal, South Africans voting, Kenya's Saudi jobs deal — plus an IN BRIEF strip.

`main.ts` is a dependency-free Node script that draws the whole front page from scratch (its own PNG encoder, its own 5x7 bitmap font) and writes a deterministic 1024x1024 `entry.png`. Run it with:

```
node main.ts
```

Output goes to `$MAKEFUN_OUTPUT_DIR`, falling back to `/output`, then `./out`.
